# Agentic Engineering: From Autonomous Agents to Governed Capabilities

Engineer useful autonomous work that stays within authority and leaves evidence you can defend.

## Teaching model

This is the SideFX teaching frame. Frameworks and models are implementations within it.

### Intent

**What human result is worth producing?**

State the purpose, the beneficiary and the exclusions before selecting an agent or tool.

Episode 1: She wants an inspection report. Publication is excluded.

Failure to expose: A broad goal is mistaken for permission to perform every useful action.

### Scenario

**What changes for the human?**

Describe Input, Event and Outcome as observable conditions. Data becomes action; action changes an experience.

Episode 1: Input: a candidate awaits inspection. Event: inspect within scope. Outcome: a useful report; publication remains pending.

Failure to expose: A list of technical tasks never establishes what success means.

### Authority

**Who may authorize the effect?**

Bind the exact request to its permitted boundary and the person or authority that can change it.

Episode 1: Inspection authority cannot silently expand into publication authority.

Failure to expose: Access to a tool is treated as authorization to use it.

### Agent responsibility

**What is the agent actually accountable for?**

Give the agent a bounded responsibility, explicit outputs and a legal continuation when a request cannot proceed.

Episode 1: The agent can propose an inspection. It cannot grant itself publication permission.

Failure to expose: The same agent supplies both the proposal and its approval.

### Capability & provider

**What meaning must survive a provider change?**

Keep the expected input, effect, output and proof obligations stable. Require a compatible realizer for that responsibility.

Episode 1: Either inspection adapter must return the same inspection product under the same authority.

Failure to expose: Changing the model quietly changes the job, its scope or its acceptance criteria.

### Execution

**What crosses into the world?**

Distinguish a decision from the effect it permits. Admit only the exact mechanic at the covered boundary.

Episode 1: An ALLOW label is a decision. It does not establish an intercepted or completed tool action.

Failure to expose: A returned status is presented as evidence that a live effect was controlled.

### Testimony

**Can the result be traced to this request?**

Retain attributable artifacts that connect request, authority, decision, provider and actual effect. Check what each artifact really supports.

Episode 1: A probe receipt must identify the session and observed effect. A diagram supplies no such receipt.

Failure to expose: Logs or model confidence are promoted into proof without a scoped claim.

### Evaluation

**Does the evidence close the promised claim?**

Compare the exact evidence with the outcome and failure obligations. Keep missing evidence separate from contradictory evidence.

Episode 1: Both deny and permit probes must close in the same identity envelope. One successful probe is insufficient.

Failure to expose: A green happy path conceals an uncovered path or stale evidence.

### Governed outcome

**Did useful work finish with authority intact?**

Close the human scenario only to the extent supported by evidence. Preserve the next decision for the authority that owns it.

Episode 1: The engineer receives her report and still controls publication.

Failure to expose: Task completion is claimed while authority or evidence has been lost.

Exercise: Resolve an out-of-scope publication to a permitted inspection, then identify the live evidence needed to establish the target boundary.

Deliverable: An authority boundary brief

Defense: Show why the requested publication stays pending, then specify the proof that would permit inspection.

## Instructor defense rubric

Score each dimension 0 (absent), 1 (asserted), or 2 (specific and supported). A self-check is not an instructor assessment or professional credential.

- **The human outcome and exclusions are explicit.** Ask: Name an action that is useful but still unauthorized.
- **Authority and agent responsibility remain separate.** Ask: Explain why access, confidence or a prior success cannot expand authority.
- **Provider substitution preserves the capability contract.** Ask: Demonstrate one compatible replacement and one incompatible candidate.
- **Each completion claim has scoped evidence and a failure test.** Ask: Show the exact missing receipt or contradictory finding that prevents closure.

Require revision when any dimension is 0. A complete classroom brief does not certify a live capability. Unresolved gaps become engineering testimony for a separate platform review.
