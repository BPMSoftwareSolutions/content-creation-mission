# Operating mode

Build an external Python content lab here. Governed repositories are read-only
source inputs. This explicit mission brief authorizes implementation in this
workspace; it does not authorize implementation in Agentic Harness.

The pipeline reads the capsule estate manifest and verifies capsule and entry
hashes. It selects the feature named in capsule lineage, falling back to one
unambiguous matching capability-tagged feature. Source snapshots remain local.
No SourceFacts service or managed admission is claimed or required for this
editorial workflow. Derived specs are candidate visual semantics, never a change
to source authority. Missing facts stay unknown. Images are downstream candidates.

Success is reproducible inventory, taxonomy, specs, generation manifests,
sample outputs, evaluation evidence and operator documentation. Platform repair,
capability promotion and repository refactoring are outside this mission.

The earlier provisioned token and eight manually authored declarations are
historical work. They are not pipeline dependencies. This implementation does
not modify or remove those previous files in the governed repository.
