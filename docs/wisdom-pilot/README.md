# Three-lesson pilot: facilitator start

**Package WP-01 · Revision 1 · Draft for review and a facilitated pilot. Learning validation pending.**

This package turns [Training Strategies, Revision 5](<../SideFX Wisdom Principles - Training Strategies.md>) §8 and §10 into usable teaching and assessment material. It proposes one cohort: engineers who review consequential software actions. No participants have been recruited, no learner responses have been collected, and no independent reviewers have signed off.

This controlled pilot package contains three short scripts, three text decision plates, separate assessment prompts, feedback exemplars, a learner reference, and empty research records. There is no certification or passing score. These fictional cases are instructional staging; they do not demonstrate platform execution. Public film adaptations are tracked separately in [production status](production-status.md); their publication does not change this package's pending learning-validation status.

## Start here

1. Read the [lesson brief and source record](lesson-brief.md), then the [facilitation procedure](facilitator-guide.md).
2. Assign actual production owners and 2–3 independent assessment reviewers in the [records template](assessment/record-templates.md). Agree the session arrangements with the cohort. Suggested planning allowance: 45–60 minutes plus a later session; adjust to observed needs, never score speed.
3. Check prior exposure individually. Freeze the selected case revisions before collecting responses. Use [substitute cases](assessment/variants-and-follow-up.md) only when they are genuinely unseen; their equivalence is unvalidated.
4. Deliver the diagnostic cards one at a time, then the scripts and their plates, then unfamiliar transfer cards. Reveal no answer exemplars or branded terms until all initial and transfer responses are saved.
5. Collect 10–20 responses across the three lessons for independent calibration. Count unique learners separately. Complete the [review and findings record](review-and-findings.md) from actual evidence before proposing expansion.

## Materials and release boundaries

| Material | Audience and timing |
|---|---|
| [Diagnostic cards](assessment/diagnostic.md) | Facilitator master; issue only the assigned card, before any instruction. C has two separately revealed parts. |
| [Script and plate A](teaching/lesson-a.md) | Facilitator script; show only the scene and prompt before the learner decides. |
| [Script and plate B](teaching/lesson-b.md) | Same staged delivery. |
| [Script and plate C](teaching/lesson-c.md) | Same staged delivery; challenges use fixed premises. |
| [Transfer cards](assessment/transfer.md) | Facilitator master; issue only the assigned card after instruction without hints. |
| [Variants and later cases](assessment/variants-and-follow-up.md) | Assessor-only bank; do not distribute the whole file. |
| [Feedback and anchors](assessment/feedback.md) | Reviewer preparation; feedback withheld until the relevant responses are frozen. |
| [Reference page](learner-reference.md) | Learners, only after all initial and transfer responses are collected. |
| [Response and exposure records](assessment/record-templates.md) | Private working copies; the checked-in template contains no learner records. |
| [Review and findings](review-and-findings.md) | Editorial self-check and empty empirical review/report fields. |

Repository separation is a delivery convention, not access control. Anyone given this folder or the strategy can inspect reserved cases. Record that access and its implications; do not call an exposed case unfamiliar. For remote delivery, send individual prompt text, not repository links or whole master files. For screen sharing, expose only the current card or plate state.

Keep completed response/exposure records outside the repository in a facilitator-controlled location; record its reference in the private session brief. Do not commit names, contact details, recordings, raw responses, or identity keys. De-identification can leave recognizable details: remove unnecessary organizational and personal references before reviewer sharing. Preserve reasoning verbatim where possible and mark any redaction.

## What happens next

The prepared materials need human editorial review, an actual cohort, and independent assessment. Those activities remain open. Use the findings to choose a limited next iteration, revise and recheck, or pause the claimed outcome. Episode 1, the remaining four lenses, and a five-channel release remain later work under the strategy.
